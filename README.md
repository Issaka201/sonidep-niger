# SONIDEP Niger

voici le logo heberge moi une site web www.sonidep.com  en blanc et bleu. SONIDEP = SOciété NIgérienne des Produits Pétroliers. Depuis 2020, elle porte officiellement le nom de Société Nigérienne de Pétrole (SONIDEP SA). [itieniger.ne], [arse.ne]

Ce qu'il faut connaître pour un site web ou un entretien

Création : 1977. [itieniger.ne], [fr.wikipedia.org]

Propriétaire : État du Niger (100 % public). [itieniger.ne], [arse.ne]

Siège : Niamey. [arse.ne], [fr.wikipedia.org]

Domaine : Pétrole et hydrocarbures. [fr.wikipedia.org], [arse.ne]

Mission principale : assurer l'approvisionnement, le stockage et la distribution des produits pétroliers au Niger. [itieniger.ne], [arse.ne]

Phrase courte à retenir

La SONIDEP est la société publique nigérienne chargée de sécuriser l'approvisionnement du pays en produits pétroliers et de développer les activités pétrolières nationales. [itieniger.ne], [arse.ne]

Pour Niger Télécoms :

Niger = pays.

Télécoms = télécommunications (téléphone, Internet, transmission de données).

Donc Niger Télécoms signifie simplement : la société nationale des télécommunications du Niger.
